# 批量调整分辨率文件范围设计

## 目标

为桌面端“批量调整分辨率”增加统一的处理范围选项：仅 IMS、仅非 IMS、全部。该范围同时约束“调整分辨率”和“转为 JPEG”两项操作。

## 处理范围

- `ims_only`：只扫描并处理 `.ims`、`.ims.jpg`、`.ims.jpeg`、`.ims.png`、`.ims.webp`、`.ims.avif`。
- `standard_only`：只扫描普通 JPG、JPEG、PNG、WebP、AVIF，IMS 命名文件必须先排除。
- `all`：同时扫描以上两类文件。
- 默认值为 `ims_only`，保持旧版本行为。

## 架构

批处理命令负责统一扫描、路径去重、并发调度、进度和结果汇总。IMS 文件继续复用现有 `resize_ims_file`；普通图片交给独立处理函数，避免改变 IMS 文件重写逻辑。两类处理结果统一映射为成功、跳过、失败。

## 普通图片规则

- 只缩小最长边超过上限的图片，不放大。
- 未启用“转为 JPEG”时保留原格式和原路径；JPEG 以 q90 编码，PNG 保留透明通道，WebP/AVIF 保留对应格式。
- 启用“转为 JPEG”时，非 JPEG 图片写入同目录同名 `.jpg`；透明像素合成到白底。
- 如果目标 `.jpg` 已存在，跳过该文件并报告冲突；源文件保持不变。
- 先在目标目录完整写入临时文件，成功后再替换或落盘。格式转换成功落盘后才删除源文件。
- JPEG/JPEG 文件已经是目标格式，只在尺寸超限时原路径缩小，不改扩展名。

## 界面与反馈

- 模态框标题改为“批量调整图片分辨率”。
- 增加“处理范围”选择框：仅 IMS、仅非 IMS、全部；每次打开默认仅 IMS。
- 扫描提示和空结果提示随范围变化，不再固定写“IMS 文件”。
- 完成后在当前窗口显示成功、跳过、失败数量。
- 冲突和处理错误进入“未处理文件”清单，逐项显示路径和原因，并提供复制按钮。
- 正常的“尺寸未超限且无需转码”计入跳过，但不进入未处理清单。

## 错误与安全

- 单文件冲突、解码失败、编码失败、写入失败或删除源文件失败不终止其他任务。
- 删除源文件失败时保留已生成的 JPEG，并将该文件记为失败，明确提示源文件仍存在。
- 多线程模式仍以文件为独立任务；扫描阶段先完成路径去重，不在处理过程中动态加入新文件。

## 验证

- 单元测试覆盖范围分类、普通图片缩小、无需处理、PNG 转 JPEG、目标冲突、透明通道合成和源文件删除。
- Rust 测试验证处理器和扫描规则；前端构建验证新增配置字段和结果区域没有语法或打包错误。
