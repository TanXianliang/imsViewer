# imsViewer

IMS 图片浏览器 — 基于 Tauri v2 的三栏图片浏览与批量转换工具。

## 功能

### 图片浏览
- **三栏布局**: 缩略图列表 | 画布显示 | 信息面板
- **IMS 容器支持**: 解析多子图 IMS 文件，按 `↑` `↓` 切换子图
- **内嵌目录缩略图**: 新 IMS 自动写入 160px JPEG 和 `IMSTHMB` Trailer，兼容旧解析器
- **文件夹导航**: `←` `→` 切换同目录文件，滚轮快捷操作
- **Canvas 渲染**: 缩放（Ctrl+滚轮）、平移（拖拽）、适应窗口 / 原始尺寸
- **拖放打开/插入**: 浏览模式拖入直接打开文件，编辑模式拖入批量插入图片
- **导出**: 导出当前图片或 IMS 全部子图
- **按需加载 + I/O 优化**: 打开 IMS 仅读索引区（文件末尾）定位封面，其余子图后台异步预加载。子图读取自适应策略（≤16MB 整读利用 OS 缓存、>16MB seek 定位），IMS 解析结果缓存复用。目录扫描只列文件名不调 metadata，同目录文件切换秒开。
- **暗色主题**: CSS Variables 暗色主题，响应式布局
- **无边框窗口**: VS Code 风格自定义标题栏，当前文件名显示，最大化/还原图标切换，原生窗口控制按钮，拖拽移动
- **右键集成**: 一键注册右键菜单"使用 imsViewer 打开"（支持 JPG/PNG/WebP/AVIF/IMS）

### 编辑模式

打开任意图片后可进入编辑模式，对子图进行增删改排序。保存时普通图片存为新 `.ims.jpg`/`.ims.png` 文件，IMS 文件覆盖原文件。

- **进入/退出**: 菜单 `编辑` → `进入编辑模式`，或 `Esc` 退出
- **保存/另存为**: `Ctrl+S` 保存到原路径，菜单 `编辑 → 另存为...` 选择目标路径
- **退出确认**: 有未保存修改时弹出对话框（保存 / 不保存 / 取消）
- **导航锁定**: 编辑模式下 `←` `→` 文件导航被锁定，`↑` `↓` 仍可切换子图
- **多选**: `Ctrl+点击` 切换选中、`Shift+点击` 范围选中
- **右键上下文菜单**: 插入图片、替换图片、删除选中
- **Del 键删除**: 删除所有选中的子图（封面除外）
- **封面保护**: 索引 0 的封面（⭐标记）不可删除、不可拖动
- **拖拽排序**: 按住缩略图拖拽调整子图顺序，视觉克隆 + 绿色插入指示器
- **拖放插入**: 从操作系统拖入图片文件到窗口，批量插入到列表末尾
- **IMS 插入**: 插入 IMS 文件时自动提取其全部子图
- **Undo/Redo**: `Ctrl+Z` 撤销 / `Ctrl+Y` 重做，30 步栈深度
- **原子写入**: 先写 `.tmp` 再替换，保存失败不损坏原文件
- **格式刷新**: 保存 IMS 时重建 v2 SHA-256 和内嵌缩略图 Trailer

### 批量转换
- 多文件夹批量扫描，按命名规范自动分组
- 支持遍历深度控制 (0-100)
- 可选输出目录，镜像输入目录结构
- 多线程并行转换 (rayon)
- 可选转换后删除源文件
- 实时进度条
- 新生成的桌面端 IMS 使用 v2 索引，并内嵌远程目录缩略图

### Android

- SAF 本地文件/目录浏览，支持 IMS/JPEG/PNG/WebP/AVIF
- SFTP 多连接、可选加密保存密码、远程目录真实缩略图和同目录左右滑切换
- 新 IMS 通过尾部 Trailer 分段读取缩略图；旧 IMS 回退为索引 + 封面分段读取
- 远程原文件缓存默认 512MB；缩略图缓存独立为 96MB LRU，可手动清理

## 使用

### 浏览模式

| 操作 | 快捷键 |
|------|--------|
| 打开文件 | `Ctrl+O` 或拖放 |
| 切换文件 | `←` `→` 或 `Shift+滚轮` |
| 跳到首/尾文件 | `Home` / `End` |
| 切换子图 (IMS) | `↑` `↓` 或 滚轮 |
| 缩放 | `Ctrl+滚轮` / `+` `-` |
| 适应窗口 | `0` / 双击 |
| 原始大小 | `1` / 双击 |
| 平移 | 拖拽 |
| 导出当前 | `Ctrl+E` |
| 导出全部 | `Ctrl+Shift+E` |
| 批量转换 | 菜单 工具 → 批量转换 |
| 批量升级 | 菜单 工具 → 批量升级 IMS |
| 右键集成 | 菜单 工具 → 注册右键菜单 |

### 编辑模式

打开图片文件后可进入编辑模式，支持插入子图、增删改排序、Undo/Redo，保存为新 IMS 文件。若打开的是 IMS 文件则覆盖原文件保存。编辑模式顶部显示橙色提示条。

| 操作 | 快捷键/方式 |
|------|------------|
| 进入/退出编辑模式 | 菜单 `编辑` 或 `Esc` |
| 多选子图 | `Ctrl+点击` 切换 / `Shift+点击` 范围选中 |
| 删除选中 | `Del` 键 或 右键缩略图 → 删除 |
| 插入图片 | 右键缩略图 → 插入 或 拖放文件到窗口 |
| 替换图片 | 右键缩略图 → 替换（仅单选时可用） |
| 拖拽排序 | 按住缩略图拖拽（封面锁定，不可移动） |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 保存 | `Ctrl+S` |
| 另存为 | 菜单 `编辑 → 另存为...` |
| 切换子图 | `↑` `↓` 或 点击缩略图（不影响选择） |

> 编辑模式下 `←` `→` / `Shift+滚轮` 文件导航被锁定，防止意外切换丢失进度。
> 封面（带 ⭐ 标记）不可删除或移动。
> 退出时有未保存修改会弹出确认提示。`Ctrl+S` 保存修改到原文件（原子写入，安全不丢数据）。

### 批量转换

1. 打开 **工具 → 批量转换**
2. 添加文件夹（可多个），设置遍历深度（0=无限）
3. 可选指定输出目录和是否保持目录结构
4. 选择是否删除源文件 / 多线程
5. 点击 **开始转换**

### 批量升级

1. 打开 **工具 → 批量升级 IMS**
2. 选择包含 IMS 文件的目录，设置遍历深度（0=无限）
3. 可选多线程加速
4. 点击 **开始升级** — 将旧版 IMS 文件就地升级到 v2（追加 SHA-256 哈希），并为缺少 Trailer 的 v2 文件补写内嵌缩略图

### CLI 工具 (Python)

```bash
# 打包为 IMS
python ims_pack.py cover.jpg sub1.jpg sub2.png -o output.ims.jpg

# 解包列出内容
python ims_unpack.py -l file.ims.jpg

# 提取全部图片
python ims_unpack.py -a file.ims.jpg -o out_dir/

# 批量打包文件夹
python ims_batch.py ./images/
```

Python 打包器写入兼容的 v1 基础条目和 `IMSTHMB` Trailer；桌面端打包器写入当前 v2 条目。可通过批量升级统一为最新 v2。

## IMS 格式

IMS (Image Set) 是一种轻量图片容器格式，将封面图 + 多张子图合并为单个文件。

```
[封面 JPEG/PNG 数据]
[子图 1 数据]
[子图 2 数据]
...
[160px JPEG 缩略图数据]
[索引: IMSIMAGE + header + entries]
[IMSTHMB Trailer (32B)]
[index_offset (4B)]
```

- 封面在文件最前端 → 普通图片查看器可显示封面
- 尾部索引记录每张图的偏移和长度 → IMS 查看器可切换子图
- 固定位置的 `IMSTHMB` Trailer 记录 160px、质量 60 JPEG 的偏移、长度、尺寸和 CRC32 → 远程浏览只需读取尾部 36B 和缩略图数据
- 旧版 IMS 没有 Trailer 时仍可正常解析，并可通过索引分段读取封面
- 子图无限制，支持 JPEG / PNG / WebP / AVIF（WebP/AVIF 自动转 PNG）
- **v2**: 每张子图附带 SHA-256 内容哈希，支持完整性校验

详见 [DESIGN.md](DESIGN.md)。

### 命名规范（批量转换）

| 角色 | 模式 | 示例 |
|------|------|------|
| 封面 | `{name}.{ext}` | `texture.jpg` |
| 子图 | `{name}_XXXXX_.{ext}` | `texture_00001_.png` |
| 输出 | `{name}.ims.{ext}` | `texture.ims.jpg` |

## 开发

# Windows 发布构建
.\buildrelease.bat

# Android Release artifact
